# 第三问 v8：以全清为前提优化单源耗时

**当前成绩：90 局独立脱机测试全部清除，平均 252.9 s/源，P95 为 324.6 s/源；200 s 目标尚未达到。** 24 局压力场景也全部清除，9 项必要回归通过。单局平均范围为 160.3–345.1 s，约 21.1% 的局落在 180–220 s。平均现实程序运行时间为 3.04 s/局。

目标口径为 **总虚拟时间 / 成功清除数**，包含搜索、移动、切频、检测、清除失败及确认搜索完成的收尾时间。200 秒是性能目标，不是脚本现实运行时间，也不是整局时间上限。最终实测见 [独立验证结果](results/iter_v8.md) 和 [逐局数据](results/iter_v8.json)。

## 算法变化

1. **区域覆盖与路径联合规划。** 为未排除区域选择补充站位，将其插入已知目标路线；比较三种覆盖量权重，使用开放路径 2-opt 减少交叉和绕行。删除冗余站位，并在保持独占区域覆盖的约束内连续调整站位。未来测点的预计覆盖只用于规划，停止判据只认可已经收到的无信号响应。
2. **短基线交会与沿途复用。** 只有一条示向度时，使用约 300 m 前进和 150 m 侧移取得交会信息；已有足够位移时优先在当前位置补测。后续根据定位多边形质心接近目标。沿途仅补充有新交会角度的测向，不在同一点反复检测以平均误差。
3. **包围圆与受控清除试探。** 半径小于 20 m 时执行有几何保证的清除，并利用剩余光学半径少走一段。半径在 20–80 m 时允许一次质心清除试探，以成功响应为准；失败后保留目标，补测并回到严格的 20 m 判据，不计为清除成功，也不永久跳过。`AdaptiveV8(probe_radius=0)` 可禁用试探；该参数变更的性能不属于本次默认版本成绩。
4. **使用无信号负证据。** 全向源最小接收半径为 1000 m，所以 `no_signal` 可排除该范围。同一源的接收半径固定，因此有信号点 S 和无信号点 N 还给出 `d(X,S) <= R < d(X,N)`，可转换为精确的线性约束。对已知源，用内接圆多边形扣除不可能区域后取保守凸包；对未知频道，用整格外接圆是否被排除圆盘覆盖维护搜索进度。边缘格也保留，不能凭格点无信号宣告整格无源。
5. **严格区分两种时钟。** 现实时间读取 `/enter.remaining_real_duration_s`，虚拟上限读取 `/enter.max_virtual_duration_s`（官方默认 360000 s）。行动前计算移动与操作耗时，不再把 1200 s 现实限时当成虚拟限时。
6. **接口一致性。** 本地对象和 HTTP JSON 响应走同一驱动；拒绝动作不触发回调；`/clear` 不切换测向机频道；网络重试复用完全相同的请求与幂等键。

全清停止条件：成功清除 16 个源，或每个频道都已经清除/完成全域无信号覆盖。限时、步数用尽、接口异常和约束矛盾分别报告，不能作为完成任务。算法只接收动作响应和自身历史，不读取模拟器的源位置、数量、接收半径或随机种子。

## 验证口径与边界

- `results/iter_v8.json` 保存代码 SHA-256、每局种子、N、清除数、完整耗时分解、退出原因、分组均值、标准差、P90/P95、均值置信区间及目标判定。
- 最终主验证使用 1410001/1510007/1610011 三个新种子组，90 个种子未用于调参。开发阶段使用 42/2024/12345 附近的 12 局及 90000–90023；站位优化前还评估过 710003/810007/910009 三组，结果保存在 `results/iter_v8_before_station_optimization.json`。压力场景另外检验 N=10/13/16、接收半径 1000/1500 m、同点固定误差、频道固定偏差、平滑空间偏差及 ±1° 端点误差。
- 本地模拟器修正为同地点误差固定，示向度保留两位小数。定位约束使用 ±1.0050001°，包含量化余量。旧版历史结果不覆盖；配对对照在同一修正后的本地模型上运行。
- 模拟场景采用圆盘内均匀布点，N 在 10–16 间均匀取整，接收半径在 1000–1500 m 间均匀抽样。这些是**脱机评估分布假设**，不是对官方案例分布的断言。
- “200 秒左右”在报告中明确按均值 180–220 s 判断，并要求各组均值也在该范围内且全部清除。单局尾部单独披露。零清除局不产生有限单源时间，但会计入全清率、零清除计数与目标失败判定。
