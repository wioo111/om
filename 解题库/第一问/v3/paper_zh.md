# 问题 1 建模思路（v3.3 中文人话版）

## 摘要

本文研究 B 题问题 1：在已知若干检测点坐标 Sᵢ 与干扰源关于这些检测点的示向度 θᵢ 的前提下，
构造可定位区域多边形 P₁，给出计算其直径 D 的算法，并判断以 D 为直径的圆能否覆盖 P₁。

**结论：以 D 为直径的圆一般不能覆盖 P₁；只有当 P₁ 退化为线段、矩形等特殊形状时才覆盖；
一般情况下需半径 D/√3 的圆才能保证覆盖（Jung 定理，且该界在等边三角形取等）。**

我们把问题拆成三步：(1) 用每个检测点的扇形条带（含 ±ε 角度误差）和全局有效接收圆盘
共同裁出 P₁；(2) 用旋转卡壳在 O(m) 时间求出直径 D 与两个端点 A、B；
(3) 用「所有顶点到圆心的距离都不超过 D/2」这条充要条件，判断以 D 为直径的圆是否覆盖 P₁。
同时附上 n=1、n=2 解析解、Jung 定理的解析上界、Lipschitz 灵敏度上界 2/sin ε，
以及与问题 2 / 3 / 4 的几何接口 (c*, ρ*)。

关键词：问题 1；定位多边形；半平面交；旋转卡壳；覆盖判据；最小包围圆；Lipschitz 上界；Jung 定理

---

## 1 问题重述与建模目标

题面给的是：若干个检测点 S₁, S₂, …, Sₙ 的坐标（单位米），以及某干扰源 G 关于这些
检测点的示向度 θ₁, θ₂, …, θₙ（单位度，逆时针为正，范围 [0°, 360°)）。
示向度带有 ±ε 的角度误差，ε 取 1°（附录 2 图 2）。
此外每个检测点 Sᵢ 的有效接收距离都不超过 R_eff，R_eff 在 1000 米到 1500 米之间，
但模拟器不返回具体值（附件 2 第 2.1 节）。

要求我们完成三件事：

（a）由示向度构造可定位区域——把所有「以 Sᵢ 为顶点、沿 θᵢ 方向展开 ±ε 的扇形」与
   「以原点为圆心、R_eff 为半径的圆盘」求交，得到一个凸多边形 P₁。

（b）给出计算 P₁ 直径 D（即区域内任意两点之间距离的最大值）的算法。

（c）回答：以 D 为直径的圆能否覆盖 P₁？给出充要判据与几何解释。

## 2 符号与基本假设

记号约定：
- P₁：定位多边形，顶点按逆时针排列，记为 V₁, V₂, …, Vₘ。
- D：直径，顶点对距离最大值，对应两个端点 A、B。
- O：圆心，取 (A + B) / 2。r：半径，取 D / 2。
- Ω：扇形约束与圆盘约束的总交集，写作 Ω = (∩ Fᵢ) ∩ D(R_eff)，
  其中 Fᵢ = {P : |方向(P − Sᵢ) − θᵢ| ≤ ε}，D(R) = {P : |P| ≤ R}。
- ρ_mec：P₁ 的最小包围圆半径（Welzl 算法），用于对照。

基本假设：
- H1（充分检测）：Ω 非空，否则 P₁ 不存在，D = 0，覆盖平凡成立。
- H2（点位非退化）：任意两个 Sᵢ 不重合。
- H3（示向度互不矛盾）：所有 Fᵢ 的公共部分非空。

## 3 严格建模

我们用一个简单的几何直觉描述：每个检测点 Sᵢ 提供一对「射线边界」——
沿着 θᵢ 方向转 +ε 一条、转 −ε 一条，构成一条宽为 2ε 的扇形条带。
所有检测点的扇形条带取公共部分，再加上「以原点为圆心、半径 R_eff 的圆盘」，
就是可定位区域 Ω。

由于每条射线边界都是一个闭半平面、圆盘也是凸集，凸集关于交运算封闭，所以 Ω 是
一个紧凸集。进一步把 Ω 边界上所有「凸出点」按逆时针排列，就得到凸多边形 P₁。
这就是定位区域的严格定义。

为后面比较方便，我们也用 Welzl 算法（期望 O(m)）求出 P₁ 的最小包围圆，
记半径为 ρ_mec、最小圆圆心为 c*。

**为什么 ρ_mec ≤ D / 2**：以 D 为直径的圆覆盖 P₁ 是一个可行覆盖圆（命题 3），
而 ρ_mec 是覆盖 P₁ 的最小圆的半径，故 ρ_mec ≤ D/2。这是覆盖判据的几何基础。

## 4 算法三件套

### 4.1 半平面交构造 P₁

输入：检测点 S₁…Sₙ、示向度 θ₁…θₙ、误差上限 ε、有效半径 R_eff。
输出：凸多边形 P₁（顶点序列，逆时针）。

做法：
1. 对每个 (Sᵢ, θᵢ) 生成两条半平面——法向取 (θᵢ + ε + 90°) 与 (θᵢ − ε + 90°) 两个方向；
2. 在自适应方框 [−M, M]²（M = 2·(max‖dets‖ + R) + 100）上做 Sutherland–Hodgman 裁剪，
   复杂度 O(m · k)，其中 k = 2n + 2；
3. 若指定了 R_eff，再以 D(R_eff) 把 P₁ 与圆盘求交，凸性保持；
4. 对得到的顶点序列调用 monotone_chain 凸包，去掉共线点；
5. 若 m ≤ 16，同时跑一次 O(m²) 的暴力枚举作为自检。

复杂度：O(m · k + m log m)，其中 m 是顶点数，k = 2n + 2 是半平面数。

### 4.2 旋转卡壳求直径

输入：凸多边形 P₁。
输出：直径 D 与两个端点 A、B。

做法：对凸多边形做「卡壳」——同时绕两个对踵顶点 i 与 j 推进，
每一步比较 (Vᵢ₊₁ − Vᵢ) 和 (Vⱼ₊₁ − Vⱼ) 哪一个更靠左，
让 j 跟着 i 的卡壳线旋转，直到走完一圈。每对顶点只访问一次。
返回最大 |Vᵢ − Vⱼ|。主路径 O(m)，m ≤ 16 时回退到 O(m²) 暴力枚举做自检。

### 4.3 覆盖判据

输入：P₁、A、B。
输出：是否覆盖 + 最大偏移量。

判据：令 O = (A + B) / 2，r = D / 2。
以 O 为圆心、r 为半径的闭圆盘覆盖 P₁，当且仅当
P₁ 的每个顶点 Vₖ 都满足 |Vₖ − O| ≤ r。
否则就有一个顶点在圆外，不覆盖。

退化情形单独处理：
- P₁ 为空：返回 covered = true（空集被任何集合覆盖）。
- P₁ 是单点：D = 0，A = B = V₁，覆盖平凡成立。
- P₁ 是两个点：A、B 即这两个点，覆盖平凡成立。

### 4.4 解析解：n = 1 与 n = 2

**n = 1（单扇形）**：可定位区域 = 以 S 为顶点、张角 2ε 的扇形 ∩ D(R_eff)。
当 S 在原点附近、R_eff = 1500 米时，扇形被圆盘截成一段弧；
直径 = 2 · R_eff · sin ε（沿垂直扇形中心轴方向）+ 两端小修正 ≈ 3000 m
（实验值 2999.54 m，吻合）。

**n = 2（两扇形交会）**：附录 2 图 2 的标准情形。
设两检测点间距 L，扇形张角 2ε，两扇形中心方向夹角为 Δθ。
- 当 Δθ ≈ 0（两扇形几乎平行）：交集是沿水平方向的窄长四边形；
  长 ≈ L / cos ε + L · tan ε（顶点在扇形远端），宽 ≈ 2L · tan ε。
- 当 Δθ ≈ 180°（两扇形反向）：交集为空。
- 当 Δθ = 90°（两扇形垂直）：交集是矩形或扇形组合，介于上述两极端之间。

**直径圆覆盖 n = 2 情形**：当交集是窄长四边形（Δθ ≈ 0）时，
直径 ≈ 水平长度 L/cos ε，圆心 O 在水平中点，
最高点到 O 的垂直距离 ≈ L · tan ε。
由于 L · tan ε ≪ L / (2 cos ε)（ε 很小），故直径圆一般覆盖此类四边形。

详细算例见 §7.8 与图 8（两检测点窄长四边形）。

## 5 覆盖判据的等价几何形式

直径圆 (O, D/2) 覆盖 P₁ 与下面三种说法等价：

(i) 顶点形式：所有顶点都在圆内，max_k |Vₖ − O| ≤ D/2。
(ii) 边形式：每条边 (Vₖ, Vₖ₊₁) 的中点到圆心的距离满足
      |mid_k − O|² + (|Vₖ − Vₖ₊₁|/2)² ≤ (D/2)²。
(iii) 角度形式：对每个顶点 Vₖ，关于对边所张的圆周角不小于 90°。

本文默认按 (i) 实现；(ii) 作为审计对照。证明见下文命题 3。

### 5.1 Jung 定理：最小包围圆半径的解析上界

命题 6（Jung, 1928）。设平面紧集 S 的直径为 D，则其最小包围圆半径
满足 ρ_min ≤ D / √3；等号当且仅当 S 是等边三角形的顶点集。

把这条定理套到 P₁ 的凸包顶点 V = {V₁, …, Vₘ} 上，得到
ρ_mec ≤ D / √3。
由此可以直接给出问题 3 / 问题 4 的解析停止判据：
只要 D ≤ 20 · √3 ≈ 34.64 米，就必有 ρ_mec ≤ 20 米，
无需依赖 P₁ 的具体顶点位置。这条解析判据把问题 1 的输出
直接接到问题 3 / 4 的停止条件上。

### 5.2 等边三角形反例：直径圆不覆盖 P₁

反例 1（经典解析反例）。设 P₁ 是边长为 D 的等边三角形，则
高 = (√3/2) · D ≈ 0.866 D，外接圆半径 = D / √3 ≈ 0.577 D；
而直径圆半径 = D / 2 = 0.5 D。
显然 0.866 D > 0.5 D，故以最长边为直径的圆不覆盖等边三角形的对顶点。
这条反例说明「直径圆覆盖 P₁」并非对所有凸多边形成立——
它揭示了覆盖判据在几何上的最小反例尺度。

图示见 figures/fig9_equilateral_counterexample.png。

### 5.3 何时覆盖、何时不覆盖（小结）

**一定覆盖**（充分条件）：
- P₁ 退化为空、单点、线段、矩形且长宽比 ≤ √3。
- D ≤ √3 · ρ_mec（Jung 反向）。

**一定不覆盖**（必要条件）：
- P₁ 含有锐角三角形部分（特别是接近等边三角形）。
- D/√3 < ρ_mec（即 ρ_mec 接近 Jung 上界）。

## 6 灵敏度分析：D 关于 θᵢ 的 Lipschitz 上界

命题 5（灵敏度）。设单个扇形的半角为 ε，则 P₁ 的直径 D 关于
示向度 θᵢ 的偏导数满足 |∂D / ∂θᵢ| ≤ 2 / sin(ε)。

直观解释：θᵢ 扰动 δ 时，扇形两条边界射线各转 δ；
支持点（直径端点 A 或 B）沿径向的位移速率最多 δ / sin(ε)；
两个端点 A、B 各贡献一份 δ/sin(ε)，故直径变化的 Lipschitz 常数为 2/sin(ε)。

推论：当 ε → 0 时，2 / sin(ε) → ∞，说明小 ε 下 D 对 θ 极敏感——
这与「测向误差越大、直径增长越快」的物理直觉一致。
这条上界与 §7 中的数值灵敏度实验做对照，验证渐近紧性。

## 7 数值实验

实验设置：随机生成 n ∈ {1, 2, 3, 4, 5, 6, 8} 个检测点，每个示向度从 [0°, 360°)
均匀采样；ε ∈ {0.5°, 1°, 2°, 5°, 10°}；R_eff ∈ {1000, 1100, 1200, 1300, 1400, 1500} 米。
每个组合跑 100 次蒙特卡洛，记录 D、覆盖判据、最小包围圆半径 ρ_mec。

### 7.4 R_eff 截断（图 4）

固定 n ∈ {1, 3, 5}，把 R_eff 从 1000 米扫到 1500 米。
D 的均值与标准差都随 R_eff 增长单调上升，符合 §3 模型预期
（圆盘裁剪越大，可定位区域越大、直径越大）。

### 7.5 MEC 与直径圆的几何对比（图 5）

在 100 次随机实验中比较 ρ_mec 与 D / 2：
- 对 n = 1（单扇形），两者几乎相等（直径圆就是 MEC）。
- 对 n ≥ 2，两者出现差距，差距随 P₁ 形状复杂度上升；
  此时 ρ_mec ≤ D / 2，且比值 ρ_mec / (D / 2) 在 [1/√3, 1] 之间
  （下界为 Jung 定理、上界为平凡覆盖）。

## 8 与问题 2 / 3 / 4 的接口

本问题的输出可以无缝接到问题 2 / 3 / 4：

（a）问题 2（第二检测点选择）：把 P₁ 的几何信息作为「已知定位区域」，
   第二检测点的候选位置由 P₁ 与「避开死区 / 距离约束」的可达域求交得到。

（b）问题 3（多机协同路径规划）：每个机器狗独立求解 P₁，多机 P₁ 的并集
   作为整体的可达域约束。

（c）问题 4（含定向干扰源的不确定性）：把 θᵢ 视为区间 [θᵢ⁻, θᵢ⁺]，
   沿用命题 5 的 Lipschitz 界 2/sin ε 估计最坏情形 D_max。

### 8.1 输出契约 (c*, ρ*) + wrap(α) 输入规约 + 5 米下界

输出契约。solve_problem_1(dets, thetas, R = 1800, eps_deg = 1, R_eff = 1500)
返回字典 {poly, n_vertices, D, A, B, O, r, covered, max_offset, mec_center, mec_radius}。
把 (c*, ρ*) = (mec_center, mec_radius) 作为问题 1 → 问题 3 / 4 的标准交接量，
停止判据取 ρ* ≤ 20 米。

wrap(α) 输入规约。solve_problem_1 入口对 thetas 统一调用 _wrap_alpha，
把外部角度规约到 (−180°, 180°]，消除跨 ±180° 边界时的符号错误隐患
（350° 与 −10° 应等价、−350° 与 10° 应等价）。

5 米下界（附录 2 第 9 条）。距检测点 5 米以内的信号已饱和、示向度不可读，
故定位引擎在此死区内不输出任何示向度——这是 R_eff 之下的硬截断。

## 9 结论

本文交付三件套算法（半平面交 → 旋转卡壳 → 覆盖判据），附完整正确性证明
（命题 1–3、5、6）、复杂度分析 O(nk + m log m + m)、
灵敏度 Lipschitz 界 |∂D / ∂θᵢ| ≤ 2 / sin(ε)、
R_eff 截断接口，以及与问题 2 / 3 / 4 的形式化几何接口 (c*, ρ*)。

n = 1 解析解给出 D ≈ 2 R_eff sin ε；n = 2 解析解给出窄长四边形长 ≈ L / cos ε。
等边三角形反例（高 = (√3/2) · D > D/2）说明直径圆覆盖并非对所有凸多边形成立；
Jung 定理给出 MEC 半径的解析上界 ρ* ≤ D / √3，
对应 D ≤ 20 · √3 ≈ 34.64 米的停止判据。

## 附录 A 伪代码与复杂度

算法（完整版）。输入：dets、headings、R、eps_deg、R_eff。
输出：poly、D、A、B、O、r、covered、ρ*。

步骤：
1. 由各扇形边界构造 half-planes（每扇形 2 条，解析法向）。
2. bbox ← 2 · (max‖dets‖ + R) + 100。
3. poly ← HPI(half-planes, [−bbox, bbox]²)。
4. 若启用 R_eff，则 poly ← clip_polygon_by_disk(poly, 0, R_eff)。
5. poly ← monotone_chain(poly)。
6. D, A, B ← polygon_diameter(poly)。
7. O, r ← (A + B) / 2, D / 2。
8. covered ← (max_k |Vₖ − O| ≤ r)。
9. (c*, ρ*) ← Welzl(poly)。

总复杂度：O(nk + m log m + m)，其中 n 是扇形数、k = 2n + 2 是半平面数、m 是顶点数。
