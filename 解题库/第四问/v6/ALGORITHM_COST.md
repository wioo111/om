# CostAwareP4算法说明

## A：正向源频道计数

`ever_observed_channels`只在direction或near响应后加入频道，清除成功不删除。16为题目源数量上界而非sim.N。观察到16个不同频道后，未知频道不再进入测量队列；原队列中的未知项在出队时也被过滤。已知频道仍完成正向补测、定位和清除。N<16时，未知频道排空仍依赖FastP4真实执行过的49站完整发现覆盖，单次no_signal不构成空间排除。

## B：扫描中原地清除

step在继续扫描前检查：当前位置是刚获得near的位置，或以当前位置为圆心、半径19.99999米的内接多边形能覆盖整个候选区域。near阈值5米且已经满足信号覆盖条件，故可以原地20米清除。不用估计中心距离替代全区域覆盖。

clear不移动到额外机会点、不推进扫描站或频道队列。父类的on_clear会推进局部任务索引，因此扫描期间成功清除后恢复该索引；成功频道加入cleared，后续不重复处理。失败的有证明原地清除报告矛盾，不标done。

## C：保守成本比较与有限光学覆盖

正向测量点的真实可接收集合是有效接收圆与定向闭半平面的交，属于凸集；已有点凸组合仍是安全补测候选。沿用FastP4/AdaptiveP4候选产生方式，不引入第三问no_signal排除。

外包区域沿用第四问 `_localize`：角度半宽1.0050001度包括1度误差与0.005度显示舍入；半径1500米圆与1800米场地圆采用切线半平面交，因此是外接近似，不会因内接圆盘近似误删真实可行位置。有效正向楔形与这些外包圆盘相交仍外包真可行位置。失败clear加入当前位置20米排除，但只减去略小于20米的内接多边形，保守保留边缘。排除列表按频道独立保存，每次重新定位后重新应用，不能丢失。

无效多边形不能作为光学覆盖证书：交付修正版返回无证书并执行原动作，不自动repair或缩小区域。确认实验原版曾在此直接报错，失败已保留并影响选型。

光学方案沿坐标轴及最小旋转外接矩形方向划分外接矩形。每格半对角线不超过19.99米，总位置数不超过6；然后用半径19.99999米的内接圆多边形并集做差，必须整个候选区域差集为空，不能仅看面积或采样点。覆盖所有矩形顶点/单元的构造与最终连续差集检查共同保证覆盖，无采样承担覆盖保证。

最多6点全排列选择最小最坏路径成本。对k点光学方案，最坏成本：

`sum(相邻移动距离)/5 + 3*(k-1) + 5`。

它含全部移动、前k-1次失败clear各3秒、最后成功clear5秒；检测与换频道费用都为0，因为clear不改变测向频道。

对每个安全补测点p，采用乐观完成成本下界：

`dist(current,p)/5 + 5 + 1[current_channel != target_channel] + max(0,dist(p,region)-20)/5 + 5`。

这含移动、检测5秒、必要换频道1秒、允许20米清除距离的最少后续移动、一次成功清除5秒。额外检测/失败/移动为非负，因此该下界不凭空忽略已发生费用，未知后续动作按最乐观0处理。只有光学最坏成本仍低于所有安全候选的最小下界才触发；否则保留FastP4原动作。本轮不声称求得全局最优；此保守下界可能漏掉有益光学方案。没有采样排序或基于真值的位置选择。

光学计划失败弹出当前位置并保留排除，成功结束该频道，最多6次clear。全部计划耗尽仍未成功立即报告几何矛盾；不重新无限启动同一方案，不跳过频道。相同点direction不作为独立几何记录，同一动作连续超过两次时报告无进展；C每频道局部决策上限256。任何此类报错或step_limit均未通过正常停止验收。

## 版本和实验边界

FastP4文件未修改，全开关关闭时直接沿用其动作和回调；ABC为同一候选类的参数组合，不复制三套策略工程。基线、独立确认版本、确认后回退修正版的哈希分别保存。

本轮最终选择FastP4。确认后修正版仅供后续新独立集验证，不能继承旧版表格的成功标签；C部署门槛仍为相对AB平均T/N至少下降5%、无单场总T增加超过10%，并先通过全清与正常停止要求。
