# 第三问 · 建模（暂不接模拟器）

## 0. 场景与目标

目标区域 `Ω = {P : |P| ≤ 1800}`；N ∈ [10, 16] 个**全向干扰源**，频道互不相同，频道集 `C = {1, ..., 20}`。
机器狗从 `O = (0, 0)` 出发，初始频道 1，速度 5 m/s，测向误差 ±1°，有效接收半径 `R_i ∈ [1000, 1500]`，近距阈值 5 m，光学清除半径 20 m。

**优化目标**：`min T_total`，约束：
- 20 分钟程序运行时间 + 25 分钟测试窗口（以先到为准）；
- 频道切换 1 秒；
- 单次检测 5 秒；
-清除未发现 3 秒，清除成功 5 秒；
- 每个干扰源只能清除一次。

## 1. 信息状态与时间模型

机器狗维护信息状态：
`S_t = (p_t, c_t, M_t, R_t, T_t)`，其中 `M_t = {(S, θ, ch)}` 已测量的示向度记录，`R_t = {ch}` 已清除频道集。

每个动作耗时 `T_act = T_move + T_switch + T_action`：
- `T_move = |p_k - p_{k-1}| / 5`；
- `T_switch = 1[ch_k ≠ ch_{k-1}]`;
- `T_action`：检测 5s；清除成功 5s，未发现 3s。

## 2. 单源定位子算法

对频道 k，若已收集 `m ≥ 2` 个示向度 `{(S_i, θ_i)}`，调用问题一的定位模型：

```
P_k = ∩ W_i ∩ Ω,   W_i = {P : |wrap(atan2(P−S_i) − θ_i)| ≤ 2°}
MEC: (c_k*, ρ_k*) = argmin_c max_{P ∈ P_k} |P − c|
```

停止判据：`ρ_k* ≤ 20 m`（满足光学精确定位 + 清除的 20 m 半径要求），可用 Jung 解析充分条件 `D_k ≤ 20√3 ≈ 34.64 m` 加速判定。

典型两检测点：D ≈ `L · tan ε / |sin β|`，ε=1°、β=90° 时 D ≈ 0.0175·L。

## 3. 三策略对比（未实装，仅建模）

| 策略 | 思想 | 频道切换代价 | 定位精度 | 总耗时 |
|---|---|---|---|---|
| **静态扫描** | 固定点采样所有频道 | 高（每点切换 N 次） | 高（多检测点交集） | 高（移动少，切换多） |
| **固定巡逻** | 沿固定路径轮询 | 中（顺序扫描） | 中（取决于路径覆盖） | 中（移动中等） |
| **闪烁跳跃** | 每检测后跳到下个候选 | 低（仅 2 个频道间跳） | 低（只有最近频道） | 低（移动多，切换少） |

**推荐混合策略**：根据信息状态自适应切换。
- 当已清除频道数 < 5：闪烁跳跃（尽快遇到新源）；
- 当已清除 5-10 频道：固定巡逻（确保覆盖）；
- 当已清除 ≥ 10 频道：静态扫描（精定位残留源）。

## 4. 静态策略的"全息图"

为每个频道 ch 在固定扫描点集 `{P_1, ..., P_K}` 上预计算：
```
A_ch[k] = simulated(measure(P_k, ch)) ∈ {direction, near, no_signal}
```

机器狗实际运行时只需查表 + 路径规划，无需在线仿真。
