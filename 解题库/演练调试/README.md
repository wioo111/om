## 已核实的操作方法

依据仓库 `原题/附件/_a1.txt` 第4节和 `_a2.txt` 第1、3—8、12节；TXT 丢失的公式通过只读提取 `附件2.docx` 的正文和数学 XML 补齐，没有进行视觉复查或修改原文件。

1. 模拟器须已登录，进入对应问题的**演练测试**，数据准备和5秒倒计时结束后才开放机器人接口。仅启动 EXE、看到端口监听，不代表可调用 `/enter`。
2. 文档只提供 `POST /enter`、`POST /measure`、`POST /clear`、`POST /exit`；未提供启动、切换问题、复位演练的 HTTP 接口。运行器不探测或调用未公开的管理接口。
3. 默认地址 `http://127.0.0.1:2026`。JSON 使用 UTF-8 无 BOM，`Content-Type: application/json`，路径不能加查询参数或尾随斜线。机器人编号来自本机登录队号，不写入算法源码。
4. **检测的5秒只计入虚拟时间，真实请求不等待5秒。** 新动作严格串行，收到完整响应再发下一个，没有正常串行请求速率上限。离线场景可以多进程并行，不等于向真实模拟器并发发动作。
5. 每个新动作使用新的 `request_id`。仅网络中断等情况下重试完全相同的动作，必须复用原请求和 ID；409 不应当成成功或改 ID 盲重试。同时检查 HTTP 状态和 `accepted`，拒绝响应里的 `virtual_time_s=0` 不能覆盖当前时钟。
6. 移动耗时为距离/5；检测5秒，接受检测时如改变频道另加1秒。清除成功5秒、失败3秒，另加移动耗时。`/clear` 的频道是目标频道，**不改变测向机频道，不收切换费**。
7. 使用 `/enter` 返回的 `remaining_real_duration_s`，不能固定假定还有1200秒。倒计时后25分钟窗口与进入后最长20分钟取较早截止，虚拟上限360000秒。结束后接口关闭，不能复位或继续原局。
8. 第四问方向覆盖为含边界的180°，接收半径未知但在1000—1500米内。单次 `no_signal` 不能剔除一个目标区域；`near` 还要求覆盖条件。20米内清除是否成功不受源朝向影响。示向度两位小数，不是精确方位。
9. 演练次数不限；正式测试每问3次，启动即占次数。本次用户禁止正式测试，因此无论说明中的建议如何，均不得启动正式测试。说明规定北京时间2026-09-13 17:30以后不可启动新测试，此前已开始的可完成。
