## 使用

从仓库根目录运行 `第三问_一键接入演练.cmd` / `第四问_一键接入演练.cmd`，
或 `第三问_一键接入正式.cmd` / `第四问_一键接入正式.cmd`。
必须先在模拟器手动选择对应问题与模式并等待接口开放；加 `-Check` 只做离线加载检查。
详细步骤见[正式接入说明](../正式运行/README.md)。

真实队号只通过 `JAMMERS_ROBOT_ID`、首次交互输入或被Git忽略的
`tools/practice.local.json` 提供，空白模板为 `tools/practice.local.example.json`。
不要把填好的配置文件提交。原始动作日志、加密正式日志、源码快照、包含本机信息的
交付包和隐私备份不作为本次新增发布内容；历史已跟踪资料维持原目录。

本次对旧日志中的真实队号做了定向脱敏，本地原件保留在被忽略的发布备份目录。
没有重写Git历史；旧提交中的原内容不会因当前文件脱敏而从历史中消失。

整理程序仅读取现有结果，不运行策略或开启模拟器：

```powershell
python tools/publish_q3_results.py
python tools/publish_q4_results.py
```

原始结果只在本机时才能重新生成全部汇总；远端提供的JSON已保留可公开的逐场
参数、指标与来源状态。请勿将整理程序的缺失本机原始文件误当成代码运行依赖。
