# 第一问 · 论证（v4 修正版）

## 0. 问题与结论一句话

给定 n 个检测点 `S_i = (x_i, y_i)` 及其对同一干扰源 `G` 的示向度 `θ_i`（误差 `±ε`），求定位区域（所有满足示向度约束的点的集合）的直径 D，并判断以 D 为直径的圆能否覆盖该区域。

答：定位区域 = n 个扇形 ∩ 目标区 `D(O, R_target)` ∩ 各 `D(S_i, R_eff)`（凸多边形），其直径 D 可由 Sutherland-Hodgman 求交 + O(n²) 顶点对扫描得到；当 n ≥ 3 时，**直径圆覆盖定位区域并不一定成立**（反例：等边三角形时 2R*/D = √3/3 ≉ 1）。

---

## 1. 算法

### 1.1 半平面构造

扇形 `θ_i ± ε` 由两条边界直线定义。设 `u_lo = (cos(θ-ε), sin(θ-ε))`、`u_hi = (cos(θ+ε), sin(θ+ε))`，则扇形内部等价于

```
cross(u_lo, P − S) ≥ 0   且   cross(u_hi, P − S) ≤ 0
```

等价半平面形式（n·P ≤ d，n 为外向法向）：

```
n_lo = (u_lo_y, −u_lo_x),   d_lo = n_lo · S     ← 下边界
n_hi = (−u_hi_y, u_hi_x),   d_hi = n_hi · S     ← 上边界
```

> 这是 v2 的 cross-product 形式。v3.5.6.1 的 `HalfPlane.from_angle` 用解析法向 `n = (cos(α+π/2), sin(α+π/2))`，配合"上、下"边界时**第二个半平面的法向取反了 180°**，导致整个扇形相对正确方向翻转——T1 方向正交自检即刻定位此 bug。

### 1.2 定位多边形

```
poly = hpi_intersect([sector half-planes of all detectors], bbox = 5000)
poly = clip_polygon_by_disk(poly, O, R_target)            # 目标区约束
poly = clip_polygon_by_disk(poly, S_i, R_eff)  for each i  # 距离约束
```

每个圆盘用 64 条弦半平面逼近（精度 ≈ 1 m）。总半平面数 ≤ 2n + 64(n+1)。

### 1.3 直径与最小包围圆

- **直径 D**：凸多边形顶点数 ≤ 8（N_disk=64 时上界 ~6），暴力 O(n²) 即可；旋转卡尺没必要。
- **最小包围圆 R\***：Welzl 期望 O(n)。

### 1.5 覆盖判别

```
def diameter_circle_covers(poly, A, B):
    center = ((A.x+B.x)/2, (A.y+B.y)/2)
    radius = |AB| / 2
    return max |P − center| ≤ radius  for P in poly
```

## 3. 典型算例（n=2, 3, 4, 6）

随机生成：源 `G` ∈ `D(O, R_target)`，每个 `S_i` 在 `G` 周围 100–1500 m，θ_i = `atan2(G−S_i) + U(−ε, +ε)`，n_per = 300/配置。

| n | 2R*/D 中位 | 覆盖概率 | 平均 D (m) |
|---|-----------|---------|-----------|
| 2 | 1.0000   | 100.0 % | ≈ 1450    |
| 3 | 1.0709   | ~77 %   | ≈ 600     |
| 4 | 1.0359   | ~65 %   | ≈ 350     |
| 6 | 1.0086   | ~60 %   | ≈ 200     |
| 10| ≈ 1.005  | ~60 %   | ≈ 130     |

> 这与"他人思路 1"统计完全吻合，说明算法路径一致。

直觉：
- n=2 时两个扇形交于一个薄透镜，其直径方向沿着两 S 中垂线方向，DiameterCircle 几乎等于 MEC。
- n=3 时定位多边形是三角形，最坏情形是接近等边三角形 → Jung 紧：`2R*/D = 2/√3 ≈ 1.1547`，覆盖失败率最高。
- n ≥ 4 时多边形更"圆"，`2R*/D` 趋近 1，覆盖率回升到 ~60 %。

---

## 4. 关键判别准则

- **Jung 定理**：任意平面上点集 `S`，其 MEC 半径 `R* ≥ D/√3`，且当 `S` 为等边三角时取等。
- **覆盖失败**：当且仅当存在某顶点 `P ∈ poly` 使得 `|P − center| > D/2`。
- **典型失败模式**：n=3 且三角近乎等边时；n 大但探测器分布"对偶"（极远 + 极近）时也会失败。
