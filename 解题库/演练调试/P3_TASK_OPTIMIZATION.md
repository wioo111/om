# 第三问：从题目目标出发的算法修改

## 题意与优化对象

重新读取 `原题/B题.pdf` 全文，第三问在第1页、设备成本在第3页；同时核对附件2接口规则。只做文字/公式提取，没有视觉复查。

要求是先确保全部干扰源被清除，再尽量缩短任务总时间。演练必须报告清除比例和平均定位清除时间 `T / 已清除数`。对全清场景分母为N，但N事前未知，不得作为算法输入。

按接受的实际动作累计：

`T = 总路长/5 + 切换次数 + 5×测向次数 + 3×光学尝试次数 + 2×成功清除次数`。

程序CPU运行时间是另一个受限指标，不是用来替代上述目标的“提速”。本轮不改变速度、成本、误差界、隐藏真值访问规则或全清标准，不启动正式测试；题目中正式测试要求不构成用户授权。

## 已实现的决策修改

核心代码为 `第三问/v10/strategy_task.py`，继承原来的一键候选 `ProbePlanP3`，不复制共享几何逻辑。

### 1. 发现满16个即可停止搜空频道

设K是通过有效测向或近距响应确认过的不同频道集合。由于每个频道至多一个源，且题目给出总数不超过16，当 `|K|=16` 时，其他频道必无目标。这一结论不要求已清除16个。

原版直到“清除满16个”才提前结束；期间仍可能检测尚未排除的空频道。新版立即把其余频道标记为不存在，保存已发现频道清单作为计数证据，同时仍须清除这16个已知源。发现10到15个时不套用此规则，也不读取模拟器事后给出的N。

### 2. 最后定位阶段以实际清除成本决策

原版主要使用固定阈值：定位包围圆半径不超过80米时尝试在估计中心清除，否则继续测向；一次失败后通常加一次测向。新版同时考虑一条能覆盖整个连续候选区域的短程光学搜索，并比较包括移动在内的预计剩余总成本。

对候选凸多边形P，考察最长对角线及各边的方向。给定轴向单位向量u、法向v，构造包含P的矩形，其法向半宽为w。取带向内保护的光学半径 `r=19.99米`：若 `w<r`，每个圆盘能够覆盖一个轴向半长 `h=sqrt(r²−w²)`、法向半宽w的矩形。

沿轴向将这些矩形连续拼接，可用有限个20米光学圆盘覆盖整个P，非仅覆盖顶点或几个采样点。每个方向比较正向和反向搜索的预计成本，保留成本最低的方案；默认最多6个位置。原对角线方向也保留，避免只因换方向丢失原候选。

对假设目标x及序列q1…qk，直到首个距离不超过20米的位置时清除成功；此前各次代价为移动时间+3秒，成功一次为移动时间+5秒。区域面积加权假设仅用于比较期望成本，不是真值，不承担覆盖证明。

只有预估比原测向/清除动作至少省1秒时才采用。没有合适的有限覆盖或没有成本优势时，保留原决策。真实响应决定是否成功，不能以预估代替清除结果。

失败尝试提供“该20米圆内无目标”的信息。新版扣除20米圆的内接多边形后取保守凸包，保留真实候选，再推进至计划中的下一个位置；不原地重复尝试，不把失败标成清除。覆盖序列是预先有界且覆盖原区域的，最多6次后必须成功或报告观测矛盾。普通、非该计划内的失败仍沿用原来的恢复机制。这里不是放宽测试断言来容忍失败，而是新增有连续覆盖保证的有限搜索分支。

### 未默认采用的候选

还实现了把光学终局成本反馈至第二测点选择、已有停靠点顺便测其他已知频道、以及至多3点的短光学方案。它们保留为离线对照，不因实现了就自动接入。开发对照中，修正方向后的完整光学方案优于这些组合；后续以新场景确认，不沿用开发集作为最终成绩。
