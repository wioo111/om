# 机器 C 开工指令

担任第三问三机协作的总控。冻结公共 v8、模拟器、几何规则、HTTP 驱动和评测器。其他两台分别返回 RouteMixin 和 MeasureMixin 候选。先读 `collab/README.md`。

检查交付的文件版本和同场景对比结果；只对一个固定候选做必要的兼容性检查，不反复审计或做视觉复查。A/B 的筛选集是开发集，不能作为最终独立成绩。

收到固定候选后，生成一次新的验收集，留在 C 本机。依次评测 A、B、A+B，公共基线自动缓存；命令见 README。必须看全部清除、异常、成对均值差、P95、N=10–12 分组和压力场景。组合收益不能由两个单项收益相加推断。若没有可信改善，继续使用 v8。

保留 RouteMixin、MeasureMixin、CombinedCandidate 的组合接口。选出胜者后，通过 `collab.live` 运行明确选中的候选，自动保存代码版本和日志；保留原 `robot.py AdaptiveV8` 回退入口。只做相关接口回归，不改官方物理规则。

官方模拟器由 C 独占。脱机验证不等于官方成绩。仅运行用户已经启动并授权的演练测试，不自动消耗正式测试次数。把真实逐动作日志和每局成绩交回 A/B，用于下一轮针对实际差异改进。

每轮输出一张基线/A/B/A+B 对比表和明确结论：采用哪版、证据是什么、200 s 目标是否达到、尚有哪些缺口。下一轮换新的独立验收集；旧失败场景可加入开发回归集。
