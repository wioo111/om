# 第四问：根据实机耗时借鉴第三问的有限迭代

## 结论与入口

新联合候选为 `FinishP4(enabled=True, trim_corners=True)`，运行名 `FinishP4_tail_grid45`。新56场确认集及112场边界集全部全清、正常停止。确认集相对FastP4平均T/N下降12.773%，最差单场增加1.940%；边界集平均下降12.848%，最差增加7.515%。

这满足相对FastP4的主门槛，但冻结清单还规定尾段机制相对GridP4的额外平均改善至少5%；实际仅2.487%，未达到该附加门槛。单独GridP4又有46.144%的最差退步，不能单独接入。因此本轮不事后修改门槛、不自动切换公共入口，当前仍使用FastP4；联合候选交给后续实机验证及整合选型。

未启用上一轮失败的CostAwareP4类。只复用其独立的连续覆盖几何函数；没有继承它的状态机。第三问、第一二问和模拟器物理规则未修改。

## 借鉴与实现

1. 借鉴第三问 `optical_strip` / `OpticalTaskP3` 的完成成本思路：只要完整候选区已有最多6个20米清除圆覆盖，就有有限清除路线。四问仍使用正向方位、1500米接收上界及1800米目标圆构成的外包区域。圆约束是切线半平面外包近似，圆覆盖检查使用内接小圆多边形，连续差集必须为空；没有目标采样充当证明。
2. 完成核心发现扫描后，只有所有仍需外围补扫的频道都具有有效覆盖，才整体结束外围；若有一个不能覆盖，保留同行的便宜补测。单频道终结成本从其当前估计中心计算，含移动/5、最多5次失败clear各3秒、成功5秒，总计不超过145秒（一次700米网格移动加检测）。该条件是有限筛选，不保证整个任务一定更快，所以必须配对评测。
3. 光学失败推进索引，失败位置保留；不重新定位、不回到恢复测量循环，原全区域覆盖仍覆盖缩小后的剩余区。成功结束真实所选频道；计划耗尽未成功报告矛盾，不能跳过频道。
4. 不借第三问no_signal的1000米空间排除。定向源的no_signal仍不能裁剪定位区；也不读取sim.N、真实位置或事后统计作决策。

## 45站发现保证和路径

删去(±2100,±2100)四个角站。其相邻内侧700米方格距原点最近点半径为1400√2≈1979.90米，大于目标圆1800米，所以这些格不与目标圆相交。任何与目标圆相交的格仍保留四角；每角距格内目标最多700√2≈989.95米<1000米，任何过目标的闭半平面至少包含一角，故仍保证全向和定向源发现。

新核心路线从原点出发，45站长度31669.84848米，对比FastP4的36400米，移动少946.03030秒。棋盘染色后黑21白24且起点黑，至少三条同色相邻边，因此长度下界为41×700+3×700√2；当前路径达到该下界。这仅证明必访45站的开放扫描路线最短，不证明整体任务时间最优。少四角及顺序变化影响定位信息，单独GridP4曾造成严重退步，不能仅凭路线证明上线。
