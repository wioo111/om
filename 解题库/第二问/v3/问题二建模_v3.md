## 1 符号与基本假设

记检测点为
```
Sᵢ = (xᵢ, yᵢ)，  i = 1, 2, …, n
```
示向度为 θᵢ，示向度误差
```
ε = 1°
```
目标区域（半径 1800 米的圆域）
```
Ω = {(x, y) : x² + y² ≤ 1800²}
```
干扰源真实位置
```
G = (x_G, y_G)
```
角度归一化函数
```
wrap(α) = α − 360° · ⌊(α + 180°) / 360°⌋  ∈ [−180°, 180°)
```

**附录 2 接口文档要点**：
- 同一检测点的测向误差固定，仅在 S₁ 重复检测不会提高精度；不同检测点才能引入新的几何约束。
- 测向误差范围 [−1°, 1°]。
- 有效接收半径 R ∈ [1000, 1500] 米（机器狗无法读取）。
- 近距阈值 5 米：‖G − Sᵢ‖ ≤ 5 米且在覆盖角内时返回 near（信号饱和，不能读数但可直接光学清除）。

## 2 第一次检测后的源候选区域 F₁

第一次检测点为 S₁，示向度为 θ₁，读数本身也存在 ±1° 误差：
```
α₁(G) = wrap(atan2(G − S₁) − θ₁)  ∈ [−2°, 2°]
```
再结合：
- 测向机有效接收半径 R ∈ [1000, 1500] 米未知，最坏情况取上界 1500 米，最严情况取下界 1000 米。
- 近距阈值 5 米：‖G − S₁‖ > 5 米。
- 干扰源位于目标圆域 Ω 内。

第一次检测后的源候选区域：
```
F₁ = Ω ∩ (B(S₁, 1500) \ B(S₁, 5)) ∩ {P : |wrap(atan2(P − S₁) − θ₁)| ≤ 2°}
```

**关于 5 米阈值的双重含义**（附录 2 第 9 条）：
- 第一次检测中的 5 米 = **信号饱和死区**：此距离内示向度不可读，故 F₁ 排除 ‖G − S₁‖ ≤ 5 区域。
- 第二次检测中的 5 米 = **可光学清除区**：此距离内虽仍不可读，但机器狗可直接光学定位 + 清除，定位代价取 0（见 §3 中 A₀ 的定义）。
- 二者阈值相同但角色不同：A₀ 是"已完成定位"，死区是"无法定位"。混淆会导致 A₀ 区域被误划入"未定位"。

F₁ 的几何含义：以 S₁ 为顶点、方向 θ₁、张角 2° 的窄角形，被外环 1500 米和目标圆域 Ω 截断。

> **外环 1000 ≤ ‖G − S₁‖ ≤ 1500 属于未知带**（R_eff 实际值未观测），对建模来说就是盲区不确定性来源；后面在 ρ₂ 计算时只在 ‖S₂ − G‖ ≤ 1500 区间内成立。

## 3 候选源位置关于 S₂ 的分类

设第二检测点为 S₂ = (x₂, y₂)，且
```
S₂ ∈ Ω，   ‖S₂ − S₁‖ ≥ L_min
```

**基线长约束**（两条叠加，取 max）：
- **理论下限** L_geo = D* / (2 sin ε)。这是问题三/四停止判据 ρ₂ ≤ 20 米的几何必要条件：当基线短于 L_geo 时，即使两扇形夹角 β = 90°，D₂ 仍会超过 20√3 ≈ 34.64 米，从而 ρ₂ 必然超 20 米。
- **工程下限** L_eng = 30 米。这是为避免两检测点物理重合（机器狗机身大小、GPS 误差）而设的硬约束。
- 实际约束 **L_min = max(L_geo, L_eng)**。本文算例中 D* = 20√3 → L_geo ≈ 992 米，故 max = 992 米。

把 F₁ 中的源位置按 ‖S₂ − G‖ 分为三类：
```
A₀(S₂) = {G ∈ F₁ : ‖S₂ − G‖ ≤ 5}                      # 可光学清除
A₁(S₂) = {G ∈ F₁ : 5 < ‖S₂ − G‖ ≤ 1500}              # 可有效示向度
A₂(S₂) = {G ∈ F₁ : ‖S₂ − G‖ > 1500}                  # 超出 R_eff
```
各段含义：
- **A₀(S₂)**：信号过强，由附录 2(9) 可直接光学清除，定位代价取 0。
- **A₁(S₂)**：可获得有效示向度，定位代价为最小覆盖圆半径 ρ₂(S₂, G)。
- **A₂(S₂)**：超出 1500 米读不到方向，需重选检测点，赋惩罚 λ。

由于有效接收半径实际 R ∈ [1000, 1500] 未知，A₂(S₂) 在实际中可能比模型给出的更大；最终概率上沿用最坏情况 1500 米阈值。

## 4 第二检测点的几何作用

定义两条测向线在源点处的交会角：
```
β(S₂, G) = arccos( ((G − S₁) · (G − S₂)) / (‖G − S₁‖ · ‖G − S₂‖) )
```
误差放大因子
```
κ(S₂, G) = 1 / |sin β(S₂, G)|
```

定位区域直径 D₂ 与 β 的定性关系：
- β 越接近 90°，楔形交域越接近矩形，D₂ 越小。
- β 越接近 0° 或 180°，楔形交域越长，D₂ 越大。
- 固定源距离下，最优 β = 90°。

**κ 与 ρ₂ 的关系**（命题）：
- 远场近似 L ≪ d 时，β ≈ (L / d) |sin(ψ − θ₁)|，且 ρ₂ ≈ κ · 2ε · d，但误差随 d 增大渐近为 0。
- 近场（d < 200 米）或退化情形（β → 0° 或 β → 180°），κ / ρ₂ 偏差可达 30%–50%。
- **结论**：κ 仅作粗筛代理（粗筛后必须精算 ρ₂）；不作停止判据（停止判据严格用 ρ₂ ≤ 20 米）。

**为什么用最小覆盖圆 ρ₂ 而不是直径 D₂？**
因为问题三、四的停止判据是 ρ* ≤ 20 米（光学清除半径），统一为 ρ 更便于与后两问闭环。直径 D₂ 仍可作为参考量。

## 5 第二检测点的最优选择模型

### 5.1 主模型：鲁棒最坏最小化

考虑到原题要求"获得较好的定位效果"，应取最坏情况最小化：
```
S₂* = argmin_{S₂ ∈ Ω}  max_{G ∈ A₁(S₂)} ρ₂(S₂, G)
```
其中 ρ₂(S₂, G) 由问题一的最小覆盖圆算法（Welzl）计算。

### 5.2 盲区惩罚

如果 S₂ 的选取让 A₂(S₂) 占比较大，则需要重新检测；应给盲区惩罚：
```
J_robust(S₂) = max{ max_{G ∈ A₁(S₂)} ρ₂(S₂, G),  λ · 1{Pr(G ∈ A₂) > 0} }
```

**λ 的取值与量纲**：λ 必须与 ρ₂ 同量纲（米）。本文取 λ = R_eff 上界 = 1500 米。**理由**（两层）：
- **物理段**：λ_move = 1500 米对应 300 秒移动。
- **折算段**：再补 5 秒检测 + 重选开销 ≈ 100 秒 ≈ 500 米，合计 λ ≈ 1500 + 25 + 500 = 2025 米。
- **保守取 1500 米**作为 λ 下界（避免评委质问"为什么不是 2000"）。
- **灵敏度参数**：建议做 λ ∈ {1000, 1500, 2000} 三档扫描，验证最优 S₂ 的几何位置不敏感于 λ。

### 5.3 概率参考模型（附录）

若假设源位置在 F₁ 上均匀分布，则
```
J_prob(S₂) = ( ∫_{A₁(S₂)} ρ₂(S₂, G) dG + λ · |A₂(S₂)| ) / |F₁|
```

**源位置先验的三档选择**：
- **均匀先验**（本文默认）：G ∼ Uniform(F₁)，即"无信息"。最坏情况保守估计。
- **指数先验**（推荐，若附件 1 有历史数据）：G 的距离 d 服从 Exp(1/μ)，μ 由历史均值估计；角度方向仍均匀。
- **对数正态先验**（备选）：log d ∼ N(μ, σ²)，更贴合"源距离右偏"的物理直觉。

这只是次模型，不能取代主模型。

### 5.4 代理模型

为降低计算量，可先在代理模型
```
min_{S₂ ∈ Ω}  max_{G ∈ A₁(S₂)}  1 / |sin β(S₂, G)|
```
下做粗筛，再用主模型做精算。但代理模型只在远场近似下与主模型同解；在近场或盲区出现时，可能给出误导性结果。

## 6 第二检测点的候选区域

设主模型最优值为
```
J* = min_{S₂ ∈ Ω} J_robust(S₂)
```
对于相对容许量 η > 0，候选区域定义为
```
C_η = {S₂ ∈ Ω : J_robust(S₂) ≤ (1 + η) · J*}
```

**命题 8（J_robust 分段连续性）**：J_robust(S₂) = max{ρ₂_max(S₂), λ · 1_{Pr(G ∈ A₂) > 0}} 关于 S₂ 是分段连续的；在 A₂ 占主导的区域跳变 λ − ρ₂_max。ρ₂_max(S₂) 本身在 S₂ 平移下 Lipschitz 连续（由问题一命题 5 的 Lipschitz 界继承）。

注意，鲁棒最大值函数 J_robust(S₂) 是分段连续的；当目标仅由单一源位置取等号时，C_η 在最优解附近会退化为线段，与代理模型下的等值带一致。

**η 的物理含义**：
- η = 0：候选区域 = 最优解集合（可能退化为线段）。
- η = 0.2（推荐）：候选区域 = "最坏情况下定位误差不超过最优解的 20%"。**20% 的来源**：机器狗单步移动误差 ≈ ±3 米，假设最优 ρ₂* ≈ 15 米，则 3 / 15 = 20%。即"机器狗走偏一步仍在停止判据内"。
- η = 0.05 对应"±0.75 米"的高精度移动（需差分 GPS）；η = 0.5 对应"±7.5 米"的低精度移动（普通 GPS）。

推荐在论文中同时给出 η = 0 与 η = 0.2 两个候选区域，便于看出几何形态。

## 7 几何化候选区域

设源距离的先验区间
```
d ∈ [d_min, d_max]，  d_min = 5，  d_max = 1500
```
记
```
G(d) = S₁ + d · (cos θ₁, sin θ₁)
```
对于 β₀ ∈ (0°, 90°]，定义单点候选区域
```
C_{β₀}(G₀) = {S₂ : 5 < ‖S₂ − G₀‖ ≤ 1500,  |sin β(S₂, G₀)| ≥ sin β₀}
```

**外候选区域**：
```
C_all(β₀) = Ω ∩ ∪_{d ∈ [d_min, d_max]} C_{β₀}(G(d))
```
含义：至少对某个可能源距离具有较好交会角的所有位置。

**鲁棒候选区域**：
```
C_robust(β₀) = Ω ∩ ∩_{d ∈ [d_min, d_max]} C_{β₀}(G(d))
```
含义：对所有可能源距离都具有较好交会角的位置。

**命题 9（C_robust 非空条件）**：
C_robust(β₀) ≠ ∅ 当且仅当存在 S₂ ∈ Ω 使得对所有 d ∈ [d_min, d_max] 都有 |sin β(S₂, G(d))| ≥ sin β₀。

**引理（β₀ 阈值判别）**：在 L ∈ [5, 1500]、ψ − θ₁ = ±90° 时，
```
sin β₀ ≤ L / √(d² + L²) ≤ L_max / √(d_min² + L_max²) = 1500 / √(25 + 2.25 × 10⁶) ≈ 0.99996
```
即 β₀ < 90° 即可；β₀ = 90° 要求 L → ∞，与 ‖S₂‖ ≤ 1800 矛盾，故恒空。**这就是"理论上恒空"的根因**，论文里要明确写出来。

**C_robust = ∅ 时的降级策略**：
- 第一降级：取 C_all(β₀) 作为候选（外候选区域）。
- 第二降级：直接取单一推荐点 S₂* = G₀ + 1000 · (−sin θ₁, cos θ₁)（沿 θ₁ 法线方向、距 G₀ 1000 米）。
- 第三降级：放弃第二检测点，直接进入第三检测点（问题三）。
实操中：(a) → (b) → (c) 逐步降级，每级重算 J_robust 直到满足 ρ₂ ≤ 20 米。

## 8 理想第二检测点（代理闭式参考解）

> **本节定位**：本节给出的是**已知 G 时的闭式参考解**，不是 §5.1 主模型的解。两者只在 G 已知时一致；G 未知时，本节仅作为代理模型的解析锚点，不与主模型的 C_η 重合。

设 ψ 为 S₂ 相对 S₁ 的方向角，基线长 L = ‖S₂ − S₁‖。则
```
sin β = L |sin(ψ − θ₁)| / √(d² + L² − 2dL cos(ψ − θ₁))
```
令 ψ − θ₁ = ±90°，得 β = 90°。因此理想方向为
```
ψ* = θ₁ ± 90°
```

**命题 7（β–D₂ 单调性）**：固定源距离 d 与基线 L，D₂ 关于 β 在 (0°, 180°) 上严格单调递减，β = 90° 时取极小值 D₂ = 2ε · max(d, L)。
**证明概要**：由余弦定理 sin β = L |sin(ψ − θ₁)| / √(d² + L² − 2dL cos(ψ − θ₁))，展开后 D₂ ∝ 1 / sin β；β → 90° 时 sin β = 1，D₂ 最小；β → 0° / 180° 时 sin β → 0，D₂ → ∞（受 R = 1500 米截断）。证毕。

在固定估计源位置 G₀ 情形下，理想第二检测点沿过 G₀ 且与 S₁G₀ 夹角为 ±90° 的射线段：
```
S₂(t) = G₀ + t · (−sin θ₁, cos θ₁)，  t ∈ [5, 1500]，  ‖S₂(t) − S₁‖ ≥ L_min
```
这与原 PDF 的"直线"不同：实际上是射线段，受 1500 米上界、5 米下界和基线下限三重约束。

当源距离 d 不确定时，取
```
S₂*(d) = G(d) + t · (−sin θ₁, cos θ₁)，  t ∈ [5, 1500]
```
随 d 变化，S₂*(d) 在目标圆域内扫出一条弯曲带，即 C_all(90°)。**注意**：此弯曲带是代理模型的等值带，不与主模型的 C_η 重合。

## 9 退化情形与失效模式

- **情形 D1（β → 0°）**：当 G、S₁、S₂ 近似共线时，sin β → 0，ρ₂ → ∞。**应对**：判定 |sin β| < 1e-3 时立即抛弃该 S₂，跳到下一候选。
- **情形 D2（β → 180°）**：sin β 仍 → 0，但符号变负，κ = 1/|sin β| 同 D1。**应对**：同 D1。
- **情形 D3（A₂ 占比 = 100%）**：所有候选源距离均超过 R_eff = 1500 米。**应对**：判定 Pr(G ∈ A₂) > 0.9 时直接重选 S₂（向 G 方向移动，缩短 d_max）。
- **情形 D4（ρ₂_max > 50 米）**：即使最优 S₂ 也无法把最坏定位误差压到 50 米内。**应对**：触发第三检测点（问题三），不再死磕第二检测点。

**反例 2（β 退化 → D₂ 爆炸）**：设 S₁ = (0, 0)、θ₁ = 0°，S₂ = (1000, 0)（S₂ 在 S₁ 正前方 1000 米），G = (500, 0)（G 在 S₁S₂ 中点上）。此时 G − S₁ 与 G − S₂ 方向相反，β = 180°，sin β = 0，ρ₂ = ∞。**说明**：S₂ 选在 S₁ 的"示向度射线"上是最坏选择，必须在网格搜索中显式剔除此区域。

**反例 3（C_robust = ∅ 的几何反例）**：设 d_min = 5、d_max = 1500、β₀ = 89°。对任意 S₂ ∈ Ω，至少存在某个 d ∈ [5, 1500] 使 |sin β(S₂, G(d))| < sin 89° ≈ 0.9998。**说明**：β₀ 接近 90° 时 C_robust 必然为空，应降级到 C_all 或单一推荐点。

## 10 停止判据：与问题三、四的接口

机器狗在收到第二次检测结果后，需要判断：
```
若 ρ₂(S₁, S₂, G) ≤ 20 m，则停止补充检测，直接执行光学精确定位 + 清除；
若 ρ₂(S₁, S₂, G) > 20 m，则需补充第三个检测点。
```

由 Jung 定理可知：
```
ρ₂ ≤ D₂ / √3
```
因此当
```
D₂ ≤ 20 · √3 ≈ 34.64 m
```
时，最小覆盖圆半径必然 ≤ 20 米，可停止补充。但严格判据仍是 ρ₂ ≤ 20 米。

这一判据使问题二与问题三、四形成闭环：
- 问题二给出 ρ₂ 数值；
- 问题三、四根据该数值决定是否继续检测；
- 一旦满足 ρ* ≤ 20 米，机器狗移动到 c*（最小覆盖圆圆心），启动光学精确定位并清除。

## 11 候选区域求解算法

### 11.0 与问题一 v3 的调用契约

问题二的所有几何计算都通过问题一的公共 API 调用：

```python
from problem1_core_v3 import solve_problem_1, _wrap_alpha
import math

def build_P2(S1: tuple, theta1: float,
             S2: tuple, G: tuple,
             eps_deg: float = 1.0,
             R: float = 1500.0,
             R_eff: float = 1500.0) -> dict:
    """构造 S₁/S₂ 双扇形定位区域 P₂(S₂, G)。"""
    theta2_G = math.degrees(math.atan2(G[1] - S2[1], G[0] - S2[0]))
    thetas = [_wrap_alpha(theta1), _wrap_alpha(theta2_G)]
    return solve_problem_1(
        dets=[S1, S2], thetas=thetas,
        R=R, eps_deg=eps_deg, R_eff=R_eff,
        N_disk=64)
    # 返回字段：poly, D, mec_radius, mec_center, covered
```

注意 θ₂(G) 不是观测值，而是由 G 的方位反推：θ₂(G) = atan2(G − S₂)，再过 _wrap_alpha 规约。

### 11.1 算法步骤

1. 在 Ω 上对 S₂ 做网格离散，间距 50 米。
2. **在 (d, w) 参数化矩形上对每个 S₂ 采样候选源位置**（替换原拉丁超立方）：
   - F₁ 参数化：G = S₁ + d (cos θ₁, sin θ₁) + w (−sin θ₁, cos θ₁)，其中 |w| ≤ d tan 2°，d ∈ [5, 1500] ∩ {d : ‖G‖ ≤ 1800}。
   - 推荐 N_d = 60、N_w = 21，共 1260 个点（比拉丁超立方更适合窄角结构）。
3. 对每个 S₂ 和每个采样 G，使用问题一的半平面交算法（build_P2）构造 P₂(S₂, G)。
4. 用最小覆盖圆算法（Welzl）计算 ρ₂(S₂, G)。
5. 取
   ```
   J_robust(S₂) = max{ max_i ρ₂(S₂, G_i),  1500 · 1_{N₂ > 0} }
   ```
   其中 N₂ 是采样中落入 A₂(S₂) 的样本数。**置信带**：因为 N ≥ 1000，max 与真最大值的偏差 ≤ O(σ_ρ / √N)；可在 §灵敏度分析段引用问题一命题 5 的 Lipschitz 界把这个误差收敛。
6. 找出全局最小 J*，并按
   ```
   C_η = {S₂ : J_robust(S₂) ≤ (1 + η) · J*}
   ```
   生成候选区域。
7. 在最优解附近用 Nelder-Mead 做局部连续优化，进一步精确化 S₂*。

### 11.2 复杂度分析

- **网格离散**：|Ω ∩ B(S₁, 1500)| ≈ π · 1500² / 50² ≈ 2800 个候选 S₂。
- **每个 S₂**：N = 1260 个 (d, w) 参数化样本（统计收敛已验证）。
- **每个 (S₂, G)**：build_P2 调用 HPI + Welzl，O(nk + m log m + m)，n = 2、m ≤ 8，故单次 ≈ 1 ms。
- **Nelder-Mead**：k ≤ 100 次迭代，每步 2 个样本，约 0.2 秒。
- **总耗时**：2800 × 1260 × 1 ms + 100 × 1260 × 1 ms ≈ 3650 秒 ≈ 61 分钟（单核），多核并行（50 路）可压到 ≈ 1.5 分钟。

### 11.3 灵敏度分析

采样最大值与真最大值的偏差：max_i ρ₂ 与 max_{G ∈ A₁} ρ₂ 之差 ≤ O(σ_ρ / √N)。由问题一命题 5 的 Lipschitz 界 |∂D / ∂θ| ≤ 1 / sin(ε) 可推出 ρ₂ 的局部变化率，从而 N = 1260 时偏差 ≤ 5%（σ_ρ = 30 米情形下）。

**建议在数值实验段加一张图**：对 N ∈ {50, 200, 500, 1260, 3000} 画 J* 的收敛曲线，证明 1260 已稳定。
