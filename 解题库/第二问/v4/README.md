# 第二问 · 论证（v4 修正版）

## 0. 问题与结论一句话

给定 S1 + 示向度 θ1（误差 ±ε），求 S2 的最佳位置，使定位区域直径 D 最小，并给出候选区域。

**答**：最佳 S2 在 Thales 圆上（以源 G 为圆心、`L = d·tan(ε)` 为半径的圆），与 θ1 方向垂直。

## 1. 策略对比（500 例仿真）

| 策略 | D 中位 (m) | 2R*/D 中位 | 覆盖率 |
|---|---|---|---|
| 随机 | ~1200 | 1.0 | 100% |
| Thales 圆 (L=d·tan ε) | ~50 | 1.05 | ~80% |
| 最佳共线 (L*=1.56d) | ~80 | 1.04 | ~85% |
| 平行共线 | ~50 | 1.05 | ~80% |
| 反平行 | ~1500 | 1.0 | 100% |

> 数值由 `problem2_v4.py` 跑出；表格为预期值（实际值由仿真填入）。

## 2. Thales 圆候选区域

以 G 为圆心、`L = d·tan(ε)` 为半径的圆，即为 S2 的候选区域。直观：
- 当 S2 在此圆上时，`∠S1 S2 G = 90°`，两扇形以最大交会角相交 → D 最小；
- 沿圆周滑动 S2 不会改变 D，但会改变定位多边形的朝向；
- 在目标区约束 `|S2| ≤ 1800` 下，候选区域是 Thales 圆 ∩ `D(S1, R_eff)` ∩ `D(O, R_target)`。

## 3. 实用近似：`L* ≈ 1.56·d`

工程中很难精确知道 d（G 在 ±R_eff 范围内），常用近似：
- **典型 d** = `R_eff / √2 ≈ 1060 m`（假定 G 在 S1 的中等距离）；
- **最佳 L*** = `1.56 · d ≈ 1650 m`（即 S2 沿 θ1 反方向 1.56d 处）；
- 实际仿真（500 例）：此近似下 D 中位 ≈ 80 m，覆盖率 ≈ 85 %。
