## 二、问题 1：建模目标的精度

修正版 §1.2.1 用「楔形」表述（凸楔形 Wᵢ = ⋂），与 v3 §3 的「扇形 → 半平面」表述等价，但修正版更早引入了角度归一化函数 `wrap(α)`、更明确区分了"楔形中心取真实示向度"和 ±ε 的扰动。**v3 缺这个 wrap 函数**。

修正版 §1.2.2 单独讨论了**情况 A（纯多边形）vs 情况 B（带圆弧边界）**两种建模选择。v3 没有这个分叉，只在代码里默认走"圆盘裁剪"路径（clip_polygon_by_disk）；理论上 v3 也能处理纯多边形情形，但论文里没说清楚。**修正版更严谨**。

修正版 §1.2.3 强调"初始矩形 [−1800,1800]² 只是裁剪容器、不能代替 Ω"，并要求裁剪后必须单独校验 `max‖Vk‖ ≤ 1800`。v3 的 Sutherland–Hodgman 直接用 `M = 1e7` 作初始裁剪框，远大于 1800，裁剪完毕靠 `clip_polygon_by_disk(poly, (0,0), R_eff)` 才收口——这个顺序是对的，但没有在论文里写出**裁剪后必须校验顶点都在 Ω 内**的提醒。**v3 应该补一条"裁剪完成后再做一次 ‖Vk‖ ≤ 1800 的兜底校验"**。

## 三、问题 1：算法细节

| 子项 | 修正版 | v3 |
|---|---|---|
| 半平面表达 | `cross(u⁻ᵢ, P − Sᵢ) ≥ 0` 与 `≤ 0` 两种符号清晰写出 | 用 `HalfPlane.n·P ≤ d` 的统一符号 |
| HPI 实现 | Sutherland–Hodgman 或标准 HPI | `hpi_intersect`（Sutherland–Hodgman）+ `monotone_chain` 凸包兜底 |
| 直径算法 | 给出 O(m²) 枚举法 + O(m) 旋转卡壳 | `polygon_diameter`：旋转卡壳 + m≤16 brute-force 自检 |
| 覆盖判据 | §1.2.5 显式写 `ρ_AB = max‖Vk − O‖ ≤ D/2` | 同判据 + 同公式 |
| 反例 | 等边三角形反例（高 = √3/2·D > D/2）——修正版新增 | v2 旧反例是数值反例，物理不成立；v3 用 fig5 / fig6 几何示意 |
| Jung 定理 | §1.2.6 显式给出 ρ_min ≤ D/√3，且等号在等边三角形取得 | v3 的 MEC 对照（Welzl）数值验证，但未写 Jung 定理上界 |

修正版的 **1.2.5 反例从数值改为等边三角形**，正是它标榜的"5 处修正"之一。**这一点比 v2/v3 写得都好**：v3 只用图，没有写出"等边三角形高 = √3/2·D"这一条简洁的反例叙述。

修正版 §1.2.6 **给出了 Jung 定理的紧上界 D/√3**，对应 ρ\* ≤ 20 m 的充分条件 D ≤ 20√3 ≈ 34.64 m——这是把覆盖判据接到问题 3/4 停止判据上的关键桥梁。**v3 没有显式写 Jung 定理**，只给了数值 MEC 对照图。**这是 v3 应该补的最重要一段**。

## 八、最终判断

- **v3 在严格性上显著强于修正版**：5 个命题 + Welzl MEC 对照 + Lipschitz 灵敏度 + 自检 6/6。
- **修正版在接口和叙述上更完整**：角度归一化、楔形 vs 圆域分叉、Jung 定理上界、(c\*, ρ\*) 直接接到第二问目标函数 J(S₂)、停止判据 ρ\* ≤ 20 m。
- **两者互补**：v3 应该把修正版的"工程口径"（wrap、情况 A/B、Jung、ρ\* ≤ 20 m、距离下界 5 m、盲区惩罚 λ）写进 §3 严格建模与 §8 接口；修正版应该把 v3 的"严格证明"（命题 1–5、复杂度分析）写进它的 1.2 节。
- **修改风险评估**：上面 §七 的 6 条动作都是局部插入（每个 ≤ 30 行），不破坏 v3 现有结构，预计 30 分钟内可以并入并重新跑 `verify_v3.py` 一次确认无 regression。
